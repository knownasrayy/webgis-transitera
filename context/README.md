# Directory Context: MAPID WebGIS Competition 2026

Direktori ini berisi seluruh dokumen referensi, panduan kompetisi, notulensi teknis, katalog data, dan proposal proyek tim. Direktori ini diisolasi dari direktori aplikasi (`WebDevelopment/`) agar proses *coding* dan *prompting* AI tetap bersih dari *token bloat*.
