# WebDevelopment Workspace

Direktori ini dikhususkan untuk seluruh *source code*, *build artifacts*, dan *deployment* aplikasi WebGIS **Pak Sibuk Ga** (A WebGIS-Based Decision Support System for Assessing TOD Readiness and Its Association with Land Value in Surabaya).

---

## 🏗️ Struktur Pengembangan (Rekomendasi)

```
webdev/
├── frontend/                 # Antarmuka WebGIS (Vite/React/Next.js/HTML, Leaflet/MapLibre, Deck.gl)
├── backend/                  # API Server, Spatial Processing & AI Proxy (FastAPI/Express/PostGIS)
└── docs/                     # Dokumentasi teknis API & arsitektur lokal
```

---

> [!NOTE]
> Seluruh panduan kompetisi, spesifikasi PRD, skema data MAPID, dan notulensi coaching tersimpan terpisah di folder `../context/`.
